# 321創世記講義 v1.1（1.1.202610131005）

把《321互動聖經》v2.18.29 的功能移植進創世記講義（繁／簡 index.html、英文 en.html）。

## v1.1 第二版（同日修正）
- 美圖預設完全照互動聖經：版型「純白簡潔」、直式 9:16、無邊框、字級特大、內建圖庫停在「風景」、相片預設「整張原圖」；稱呼「親愛的家人：平安！」、團體「國度321空中團契」、署名「願上帝賜福你！」。
- 整張原圖的文字照互動聖經重做：文字大小預設 110%（滑桿 50–250%、兩指捏合），經文／問候語兩種，經文下方的祝福另外寫（小智寫祝福 50 字內、改一改、不要祝福），可用手指拖動或方向鍵微調、一鍵回到自動位置。
- 相片模式補齊四種：當背景、貼在卡片上（形狀／大小／位置）、原圖（相片完整不裁切，自動上圖下字或左圖右字）、整張原圖。
- 我的相片庫：用過的相片自動留在手機（最多 40 張），下次進美圖自動接回上次那張。
- 小智回答排版：小標題、重點引言、粗體、條列、對照表，畫面更好讀；最重要的那一句會被做成美圖。
- 小智的字體跟著 App 字級一起放大縮小。

## 新增
- 小智：十種回答對象（成人、青少年、兒童、慕道友、長輩、單親、單身、父母、夫妻、牧者）；回答長度 簡要／適中／詳細（切換時用新長度重新回答）；回答後的追問鈕；回答被截斷時自動接著寫完；新回答進來時舊的長回答自動收起，頂列「收合」一次收合全部；每則回答多了「分享」「美圖」。
- 讀經樂（工具 → 讀經樂；經文頁底「考考我這一章」）：小智照該章出題，聖經猜謎＋讀經測驗、錯題本（離線可複習）、最佳成績。
- 美圖工作室（畫線面板「做一張圖」、小智回答「美圖」）：9 版型、5 尺寸、6 外框、5 段字級；內建圖庫（與互動聖經共用 299 張）、Pexels 免費圖庫、自己的相片；整張原圖／當背景；稱呼、團體名、署名；小智寫祝福、改一改、用我的領受。

- 我的作品（我的 → 我的作品）、聚會與奉獻（我的 → 聚會與奉獻；今日頁有團契簡介與下一堂聚會倒數）。
